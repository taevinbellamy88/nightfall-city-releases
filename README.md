# nightfall-city-releases
Nightfall City desktop installers and update files (Windows). Requires an activation key. Source code is private.

## Download

Get the latest installer from [Releases](https://github.com/taevinbellamy88/nightfall-city-releases/releases/latest) (`NightfallCity-Setup-<version>-x64.exe`) or from [nightfallcity.cpengine.store](https://nightfallcity.cpengine.store).

## Buy

Nightfall City needs an activation key. Buy one at [nightfallcity.cpengine.store](https://nightfallcity.cpengine.store/#offers); it arrives by email. Paste it into the app's activation screen.
